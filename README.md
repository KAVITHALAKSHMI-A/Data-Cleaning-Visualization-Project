# Data-Cleaning-Visualization-Project
Data Cleaning &amp; Visualization project using Python, Pandas, Matplotlib, and Seaborn. Includes data preprocessing, outlier treatment, exploratory data analysis, and dashboard creation.

## Project Overview

This project demonstrates the complete data preprocessing and visualization workflow using Python. A raw sales dataset containing missing values, duplicate records, and outliers was cleaned and analyzed to generate meaningful business insights through visualizations.

## Objectives

* Handle missing values in the dataset.
* Detect and remove duplicate records.
* Identify and treat outliers using the IQR method.
* Perform exploratory data analysis (EDA).
* Create visualizations to communicate key insights.
* Learn data preprocessing, visualization, and storytelling with data.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Dataset Description

The project uses a sales dataset containing:

* Date
* Category
* Region
* Sales
* Units Sold
* Discount
* Customer Rating
* Month
* Revenue

The raw dataset intentionally contains missing values, duplicate records, and outliers to simulate real-world data quality issues.

## Data Cleaning Process

### 1. Handling Missing Values

* Missing sales values were filled using the median.
* Missing ratings were filled using the mean.
* Missing discount values were replaced with 0.

### 2. Removing Duplicates

* Duplicate rows were identified and removed from the dataset.

### 3. Outlier Treatment

* Outliers were detected using the Interquartile Range (IQR) method.
* Extreme values were capped to reduce their impact while preserving records.

### 4. Feature Engineering

* Extracted month information from the date column.
* Calculated revenue using sales, units sold, and discount values.

## Visualizations Created

### Revenue by Category

Shows the total revenue generated by each product category.

### Monthly Revenue Trend

Displays revenue trends across different months.

### Outlier Analysis

Compares data distribution before and after outlier treatment using box plots.

### Correlation Heatmap

Shows relationships between numerical variables in the dataset.

## Results

* Raw dataset size: 315 records
* Duplicate records removed: 15
* Final cleaned dataset size: 300 records
* Outliers treated: 9
* Top-performing category: Furniture
* Best-performing month: Month 5
